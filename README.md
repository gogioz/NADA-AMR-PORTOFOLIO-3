# Nada Ghonemy: Portfolio website

Next.js (App Router, JavaScript) + Tailwind CSS. Pages: Home, Work, Gallery, Reports, About, Contact.

    npm install
    npm run dev        # http://localhost:3000

## Update content
- `data/site.js`: contact details, films (YouTube IDs and titles), reports, gallery photos, services.
- `data/cv.js`: experience, skills, education, training (About page).
- Gallery: copy images into `public/gallery` and list them in `gallery` in `data/site.js`.
- Colors: `tailwind.config.js` (`moss` #436B5C, `blush` #EFBBBD).
- Deploy: push to GitHub and import on vercel.com.
